# Pure HTML Homepage

This is a standalone static version of the personal homepage.

## What this folder contains

- `index.html`: Main homepage file
- `styles.css`: Page styles
- `assets/humandreamer_500x250.jpg`: Featured publication image

## Local preview options

1. Open `index.html` directly in a browser.
2. Use a local static server (recommended):

```bash
cd pure_html_homepage
python3 -m http.server 8080
```

Then open http://localhost:8080

No Ruby, Jekyll, or Bundler is required for this folder.
